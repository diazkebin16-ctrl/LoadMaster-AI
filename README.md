# LoadMaster AI v5.12 REPEATABLE SOLVER

Esta versión convierte soluciones ocasionales en resultados más repetibles.

- Normaliza y compacta cada candidato antes de puntuarlo.
- Reintenta insertar pendientes después de cada compactación.
- Ejecuta varias rondas independientes con semillas diferentes hasta 30 segundos.
- Guarda automáticamente una carga completa como patrón comprobado.
- Conserva el mejor resultado previo y no acepta regresiones.
