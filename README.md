# LoadMaster AI v5.13 IMAGE EXPORT

Esta versión conserva el motor repetible de v5.12 y añade exportación visual.

## Cambios principales

- Nuevo botón **Guardar imagen** en Guardar / exportar.
- Exporta únicamente el plano de carga como archivo PNG, con medidas del tráiler, cantidad de pilas y pallets.
- Cada patrón guardado incluye una miniatura generada desde el plano actual.
- La biblioteca de patrones muestra la miniatura junto al nombre y sus datos.
- Los patrones antiguos siguen funcionando y muestran “Sin vista previa”.
- Si el almacenamiento local no permite guardar todas las imágenes, la aplicación conserva los patrones sin miniatura en vez de perderlos.
- Caché actualizada a v5.13.

## Uso

1. Acomoda o optimiza la carga.
2. En **Guardar / exportar**, pulsa **Guardar imagen** para descargar un PNG.
3. Para asociar la misma vista a un patrón, escribe su nombre y pulsa **Guardar patrón**.
